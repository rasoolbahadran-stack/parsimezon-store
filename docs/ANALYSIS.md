# گزارش مهندسی معکوس parsimezon.ir — قبل از توسعه

> بررسی واقعی و زنده سایت مرجع انجام شده است (HTML خام، ۳۰ فایل CSS واقعی، متغیرهای inline قالب و بررسی مرورگر). مواردی که با ابزارهای موجود قابل استخراج نبودند، صریحاً به‌عنوان تخمین علامت‌گذاری شده‌اند.

## ۱. مشخصات فنی مرجع
- پلتفرم: WordPress + قالب **WoodMart** + **WooCommerce** + LiteSpeed Cache
- جهت: RTL فارسی، فونت **IRANYekan** (تجاری → در بازسازی با **Vazirmatn** جایگزین می‌شود)
- دامنه‌ی دسته‌های برند: `/product-category/p/{arp,dal,epl,...}` — هر برند یک کد سه‌حرفی دارد (۱۹ برند شناسایی شد)

## ۲. ساختار سایت و صفحات شناسایی‌شده
- خانه (`/`)، فروشگاه/دسته‌ها (`/product-category/...`)، محصول (`/product/...`)، سبد، تسویه، حساب کاربری، وبلاگ، درباره/تماس (استاندارد Woo/WoodMart)
- درخت دسته‌بندی واقعی:
  - **لباس زنانه و دخترانه**: پیراهن/سارافون/ماکسی/اورال/سرهمی، تاپ/نیم‌تنه/تی‌شرت/بادی، دامن (بلند/کوتاه)، ست/کت‌شلوار/بلوزدامن، مانتو و …
  - **شال و اکسسوری**: روسری، شال
  - **کیف و کمربند**: کیف، کمربند
  - **جوراب**
- URLها واقعاً بازدید و استخراج شدند؛ اسلایدر دقیقِ هیرو در HTML خام بارگذاری تنبل دارد (محدودیت ابزار: اجرای اسلایدر ثبت نشد → بازسازی با Swiper-مانند CSS/JS سبک انجام می‌شود)

## ۳. Design System استخراج‌شده (از CSS واقعی)

## ۴. تایپوگرافی واقعی
- بدنه: ۱۴px / وزن ۴۰۰ — تیتر بخش‌ها: وزن ۶۰۰ — عنوان محصولات: ۵۰۰ — عناصر هدر: ۱۳px / ۷۰۰ — عنوان ویجت: ۱۶px / ۶۰۰
- اندازه‌های رندر مرجع: ۱۱–۲۰px؛ قیمت‌ها با اعداد فارسی و جداکننده هزارگان (نمونه واقعی: ۵۴۸,۰۰۰ / ۱,۵۷۸,۰۰۰ / ۳,۶۴۸,۰۰۰ تومان)
- بازسازی: **Vazirmatn** با همان مقیاس (Numbers فارسی با `toLocaleString('fa-IR')`)

## ۵. سبک تصاویر
- تصاویر محصول: پرتره ۳۰۰×۴۰۰ (نسبت ۳:۴)، عکس‌های استودیویی ویرایش‌شده (Picsart)، پس‌زمینه‌های رنگی/ساده، کراپ تمام‌قد لباس
- بنر هیرو ویدیویی/عکس بزرگ تمام‌عرض؛ تصاویر دسته‌ها کوچک
- بازسازی با عکس‌های استوک مشابه سبک (پرتره ۳:۴ لباس زنانه استودیویی) در فرمت **WebP** — از کپی مستقیم فایل‌های سایت مرجع اجتناب شد

## ۶. انیمیشن و تعامل (مشاهده + تخمین بر اساس الگوی WoodMart)
- هدر چسبنده با کوچک‌شدن در اسکرول؛ نوار اطلاع‌رسانی بالای هدر با دکمه بستن
- گرید محصولات: هاور → بزرگ‌نمایی ملایم تصویر + نمایش دکمه افزودن به سبد
- منوی چندستونه (mega menu) با fade/dropdown
- بارگذاری بی‌نهایت (infinite scroll) برای گرید ۴ ستونه → بازسازی: دکمه «نمایش بیشتر»
- اسلایدر هیرو با autoplay (تخمین duration ~۵s، easing ease-out) — مقادیر دقیق از JS فشرده قابل استخراج نبود
- سبد کشویی (drawer)، تُست افزودن به سبد، شمارنده کالا روی آیکون
- بازسازی با IntersectionObserver (fade-up در اسکرول) و transitionهای ۰٫۲–۰٫۴s

## ۷. فروشگاه و جریان خرید مرجع
- ووکامرسی استاندارد: انتخاب تنوع (رنگ/سایز)، تعداد، افزودن به سبد، کوپن، هزینه ارسال، پرداخت درگاه
- بازسازی: جریان کامل **Demo** با LocalStorage + درگاه پرداخت آزمایشی داخلی (بدون بانک واقعی)

## ۸. Mobile UX
- منوی همبرگری کشویی، جست‌وجوی موبایل، لوگوی وسط، آیکون‌های حساب/سبد؛ گرید محصولات ۲ ستونه در موبایل (الگوی WoodMart)
- Sticky bottom bar در صفحه محصول (الگوی قالب، ارتفاع ۹۵px طبق متغیر CSS)

## ۹. موارد غیرقابل بررسی (محدودیت ابزار)
- اجرای زنده انیمیشن‌های اسلایدر و مقادیر دقیق JS (فایل‌های JS فشرده LiteSpeed)
- صفحات داخل حساب کاربری/تسویه واقعی (نیاز به لاگین واقعی دارد — بازسازی بر اساس الگوی استاندارد ووکامرس انجام می‌شود)
- فونت IRANYekan (تجاری) — جایگزین: Vazirmatn طبق الزام پروژه

## ۱۰. تصمیم‌های بازسازی
- Astro ۴ برای فروشگاه استاتیک + Next.js 14 (Static Export) برای پنل مدیریت زیر مسیر `/admin`
- انتشار: GitHub Pages مخزن `rasoolbahadran-stack/parsimezon-store` با base path `/parsimezon-store`
- Design Tokens یک‌به‌یک مطابق جدول بالا؛ بدون کپی متن/عکس مرجع — محتوای فارسی اصلی و عکس استوک مشابه
