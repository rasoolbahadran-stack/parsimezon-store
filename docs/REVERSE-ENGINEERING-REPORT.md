# گزارش مهندسی معکوس parsimezon.ir — ۱۶ بخش کامل

> روش بررسی واقعی: دانلود HTML خام صفحه اصلی، دانلود ۳۰ فایل CSS واقعی قالب، استخراج متغیرهای inline قالب WoodMart، بازکردن زنده سایت در مرورگر headless (viewport دسکتاپ ۱۴۴۰×۹۰۰) و خواندن computed-style عناصر واقعی (بدنه، هدر، دکمه‌ها، فوتر). هر مقداری که با ابزارها قابل استخراج نبود، صریحاً «تخمین» یا «غیرقابل استخراج» علامت خورده است.

## ۱. ساختار سایت

- پلتفرم: **WordPress** + قالب **WoodMart** + **WooCommerce** + LiteSpeed Cache (تأیید از نام فایل‌های CSS/JS و متغیرهای `--wd-*`)
- جهت: RTL فارسی؛ فونت پایه IRANYekan
- ساختار کلی: نوار اطلاع‌رسانی بالای هدر → هدر چسبنده → هیرو/اسلایدر → گرید محصولات → پیش‌فوتر → فوتر تیره
- کانتینر اصلی: `--wd-container-w: 1600px` (رندر واقعی در viewport ما: ~۱۴۲۵px)
- فاصله ستون‌ها: `--wd-column-gap: 5px`
- دسته‌بندی‌ها در دو سطح با URLهای `/product-category/{دسته}/{زیردسته}/`
- ۱۹ دسته برند با کد سه‌حرفی در مسیر `/product-category/p/{arp,dal,epl,hnl,krn,lsk,mil,mis,mjd,nat,par,rad,ras,shi,tid,tin,tor,val,zik}`

## ۲. صفحات شناسایی‌شده (URLهای واقعی بازدید/استخراج‌شده)

| صفحه | الگوی URL واقعی |
|---|---|
| خانه | `/` |
| فروشگاه/دسته‌ها | `/product-category/clothes/…`، `/product-category/shawl-scarf/…`، `/product-category/belt-purse/…`، `/product-category/socks/` |
| زیردسته‌ها | `clothes/dresses-overalles/overall`، `…/sarafon`، `…/maxi`، `…/dress`، `top-tshirt/top`، `…/tshirt`، `skirt/long-skirt`، `skirt/short-skirt` |
| محصول | `/product/…` (الگوی استاندارد ووکامرس — صفحات محصول از گرید خانه استخراج شد) |
| سبد / تسویه / حساب | مسیرهای استاندارد Woo (`/cart`، `/checkout`، `/my-account`) — صفحه اصلی و گریدها به‌صورت زنده بررسی شد |
| robots.txt | بازدید شد (مسدودسازی `/wp-admin` و `wp-login` — الگوی پیش‌فرض WP) |

## ۳. Layout

- گرید محصولات: `grid-columns-4 elements-grid` با pagination بی‌نهایت (`wd-products` + `wd-loop-footer`)
- کارت محصول: نسبت تصویر ۳:۴ (رندر ۳۰۰×۴۰۰)، بدنه کارت شامل دسته، عنوان، قیمت
- هدر: سه ردیف تنظیم‌شده در WoodMart با ارتفاع‌های متغیر؛ عملاً ردیف اصلی sticky با ارتفاع sticky ۵۰px (`--wd-header-general-sticky-h: 50px`)
- عرض هیرو: تمام‌عرض با پارالاکس (`--wd-parallax-pos: center`)

## ۶. سبک تصاویر

- محصولات: پرتره ۳:۴ (۳۰۰×۴۰۰)، عکاسی استودیویی ویرایش‌شده، پس‌زمینه ساده/رنگی، کراپ تمام‌قد لباس
- هیرو: بنر بزرگ تمام‌عرض (نمونه واقعی `uploads/2020/08/1-scaled-…jpg`)
- نام فایل‌ها نشان‌دهنده ویرایش موبایلی (Picsart) است — یعنی تصاویر داخلی تولید/ویرایش می‌شوند، نه استوک
- **تصمیم بازسازی**: به‌جای کپی فایل‌های مرجع، عکسی استوک با همان نسبت ۳:۴ و سبک استودیویی پیدا و به WebP تبدیل شد (۱۲ محصول + ۲ هیرو + بلاگ/درباره ما؛ ۸ تا ۱۱۳KB)

## ۷. ساختار Header

- نوار بالایی (header-banner) با دکمه بستن (`wd-hb-close`)
- ردیف اصلی: لوگو (موبایل وسط) → منوی اصلی چندسطحی با mega menu → جست‌وجوی پیشرفته WoodMart (با dropdown دسته) → حساب کاربری (hover) → سبد خرید (design-2 با شمارنده)
- رفتار sticky: بعد از اسکرول، ردیف چسبنده ۵۰px
- رنگ عناصر هدر: `#333` / هاور `rgba(51,51,51,.6)`

## ۸. ساختار Footer

- پس‌زمینه مشکی، متن سفید ۸۰٪، لینک‌های سفید ۷۲٪ (الگوی استاندارد WoodMart footer)
- بلوک‌ها: درباره + شبکه‌های اجتماعی | دسته‌بندی‌ها | لینک‌های سریع | ویجت‌ها/اطلاعات تماس
- بخش پیش‌فوتر جدا (`wd-prefooter`)
- در بازسازی: ۴ ستون + خبرنامه + نشان‌های اعتماد + کپی‌رایت

## ۹. ساختار صفحات داخلی (الگوی WoodMart/Woo)

- صفحه دسته: سایدبار فیلتر + گرید ۴ ستونه + ابزار مرتب‌سازی
- صفحه محصول: گالری چپ (در RTL سمت چپ) با بندانگشتی‌ها، خلاصه راست: عنوان/رتبه/قیمت/تنوع/تعداد/افزودن به سبد، تب‌های توضیحات-مشخصات-نظرات، محصولات مرتبط
- نوار چسبنده پایین صفحه محصول در موبایل (`--wd-sticky-btn-height: 95px`)

## ۱۰. Animation و Motion

- هدر: تغییر سایه/کوچک‌شدن در اسکرول (sticky row)
- کارت محصول: هاور → نمایش دکمه افزودن به سبد با transition عمودی (الگوی WoodMart) و بزرگ‌نمایی ملایم تصویر (تخمین duration ~۰٫۵s)
- mega menu: fade/dropdown هنگام hover (تخمین ~۰٫۲s)
- اسلایدر هیرو: autoplay — مقادیر دقیق duration/easing در JS فشرده LiteSpeed قابل استخراج نبود (تخمین: ۵s / ease-out)
- بازسازی با همان الگوها: IntersectionObserver برای ورود عناصر (fade-up ۰٫۶s)، drawer سبد ۰٫۳۵s cubic-bezier، تُست، شمارش معکوس

## ۱۱. Interaction و رفتار کاربر

- جست‌وجوی هدر با dropdown دسته‌بندی و نتایج زنده (فایل‌های CSS جدا: `wd-search-results`, `wd-search-cat`)
- سبد کشویی با تغییر تعداد و حذف (فایل CSS جدا `wd-header-cart`)
- فیلتر/مرتب‌سازی در فروشگاه، انتخاب تنوع و تعداد در محصول، کوپن در سبد (الگوی ووکامرس)
- بارگذاری بی‌نهایت گرید محصولات
- در بازسازی: همه تعاملات بالا به‌صورت قابل استفاده پیاده شد + جریان کامل خرید دمو (کوپن → ارسال → پرداخت آزمایشی → تأییدیه → پنل)

## ۱۲. Mobile UX

- منوی همبرگری کشویی (`wd-header-mobile-nav`، mobile-style-icon)، لوگوی وسط هدر موبایل، آیکون حساب/سبد
- جست‌وجوی موبایل جدا (`wd-header-search-mobile`)
- گرید محصولات ۲ ستونه در موبایل (الگوی قالب — تخمین بر اساس گرید responsive وودمارت)
- نوار چسبنده پایین صفحه محصول (۹۵px)

## ۱۳. ساختار فروشگاه

- ووکامرس استاندارد: دسته/زیردسته چندسطحی، برند به‌صورت دسته اختصاصی (`/p/{کد سه‌حرفی}`)، تنوع (رنگ/سایز)، قیمت با/بدون تخفیف، موجودی
- جریان خرید: سبد → کوپن → ارسال → پرداخت درگاه
- در بازسازی: همان جریان به‌صورت Demo کامل با LocalStorage (بدون بانک واقعی) + هم‌رسانی داده با پنل مدیریت

## ۱۴. عناصر شاخص طراحی (signature elements)

1. دکمه‌های تیز قرمز `#ED1844` با سایه داخلی پایین

3. کارت محصول با هاور zoom + دکمه کشویی
4. فوتر مشکی پررنگ
5. اعداد فارسی قیمت‌ها
6. نوار اطلاع‌رسانی قابل بستن بالای سایت
7. گرید ۴ ستونه فشرده (gap ۵px)

## ۱۵. جزئیات قابل بازسازی (نقشه پیاده‌سازی انجام‌شده)

- توکن‌های بالا یک‌به‌یک در `src/styles/global.css` سایت به‌صورت CSS variables
- ساختار هدر/فوتر/گرید/کارت/تب‌ها/دروار مطابق الگو
- درخت دسته‌بندی ساده‌شده به ۶ دسته دارای محصول + برندهای دمو
- فونت Vazirmatn با همان مقیاس (۱۴px بدنه، تیترها ۶۰۰/۸۰۰)
- قیمت‌گذاری واقع‌گرایانه در بازه مشاهده‌شده مرجع (۳۸۸هزار تا ۳.۶میلیون تومان)

## ۱۶. موارد غیرقابل بررسی (محدودیت ابزار — صادقانه ثبت می‌شود)

- **مقادیر دقیق JS اسلایدر** (duration/easing دقیق): فایل‌های JS با LiteSpeed فشرده و بدون sourcemap
- **صفحات داخل حساب کاربری و تسویه واقعی**: نیازمند لاگین واقعی/سبد پر با پرداخت بانکی — بازسازی بر اساس الگوی استاندارد ووکامرس انجام شد
- **رفتار کامل infinite scroll**: اجرای زنده اسکرول‌های متوالی در ابزار headless پایدار نبود؛ الگو از ساختار HTML (`pagination-infinit`) و فایل‌های CSS استخراج و با «نمایش بیشتر» بازسازی شد
- **فونت IRANYekan**: فایل تجاری قابل استفاده مجدد نیست — جایگزین Vazirmatn طبق الزام پروژه
- **سایز دقیق برخی بنرهای تبلیغاتی دورابطه‌ای**: تصاویر lazy-load کامل رندر نشدند؛ فقط بنر اصلی هیرو استخراج شد
