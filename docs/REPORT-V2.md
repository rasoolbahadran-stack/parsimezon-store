# گزارش ارتقای PARSIMESON به نسخه ۲ — فروشگاه مد در استاندارد حرفه‌ای

> وضعیت انتشار: **سورس کامل روی branch جدید `v2-upgrade` پوش شده است؛ production (main و GitHub Pages) کاملاً دست‌نخورده باقی مانده.** طبق بخش ۱۹ مأموریت، انتشار فقط پس از دستور صریح شما انجام می‌شود.

## ۱. چه چیزی توسعه یافت

### Design System نسخه ۲ (Editorial Fashion)
- بازطراحی کامل توکن‌ها: پالت مرکب با مشکی جوهری `#161412`، پس‌زمینه عاجی `#FAF7F2` و قرمز برند `#ED1844` به‌عنوان اکسنت محدود
- تایپوگرافی ادیتوریال: تیترهای ۹۰۰ وزنه با `letter-spacing` کنترل‌شده، لیبل‌های لاتین با فاصله حروف (COLLECTIONS، NEW ARRIVALS، …)
- موشن سیستم‌مند: منحنی‌های `--ease-out` و `--ease-spring`، reveal مرحله‌دار (delay کلاس‌ها)، اسکلتون shimmer، و **پشتیبانی کامل `prefers-reduced-motion`** (خاموش‌کردن همه انیمیشن‌ها)
- گوشه‌های تیز (radius ۰–۴px)، سایه‌های لایه‌ای ملایم، سطر ۱px به‌جای کادرهای سنگین — زبان بصری برندهای premium fashion

### Header و ناوبری
- هدر شیشه‌ای (backdrop-blur) چسبنده با تغییر سایه در اسکرول
- **Mega Menu سه‌ستونه واقعی**: ستون دسته‌های اصلی + گرید همه ۲۰ دسته با شمارش + تصویر ویژگی کالکشن — هاور و کیبورد (`:focus-within`)
- **جستجوی زنده** با پیشنهاد محصول (تصویر+قیمت+دسته) و **نرمال‌سازی فارسی کامل** (ی/ي، ك/ک، ة، حروف presentation-forms عربی با NFKC، حذف نیم‌فاصله و اعراب) — تست‌شده با تایپ عربی «پالﺘﻮ»
- مودال جستجوی تمام‌صفحه، آیکون‌های علاقه‌مندی و مقایسه با شمارنده، **Bottom Navigation موبایل** (خانه/فروشگاه/جستجو/علاقه‌مندی/سبد)
- منوی کشویی موبایل با آکاردئون دسته‌ها

### صفحه اصلی — ۱۱ بخش
اسلایدر هیرو سه‌اسلایدی با فلش/دات/اتوپلی و توقف در هاور ← کالکشن‌های ویژه (۴ کارت تصویری) ← دسته‌بندی‌های تصویری (۱۰ کاشی) ← تازه‌های هفته (۸ محصول) ← نوار کمپین با شمارش معکوس ← محبوب‌ترین‌ها (اسکرول افقی snap) ← استایل پیشنهادی (Lookbook با هات‌اسپات + محصولات ترکیب) ← پیشنهادهای ویژه ← ادیتوریال مجله (گرید نابرابر) ← خبرنامه ← فوتر ۵ستونه کامل با خدمات مشتریان، راهنمای خرید، خبرنامه و اعتبار «کافه دانش» با لینک

### کارت محصول جدید
تصویر دوم در هاور، ۴ نوع Badge (تخفیف٪، پرفروش، جدید، ناموجود)، نقطه‌های رنگ واقعی از پالت، سه ابزار شناور (علاقه‌مندی، مشاهده سریع، مقایسه)، دکمه افزودن سریع + مشاهده سریع، انیمیشن ورود کارت

### صفحات دسته‌بندی — فیلترهای واقعی (۲۰ صفحه استاتیک + صفحه فروشگاه با چیپ‌ها)
- بنر اختصاصی با توضیح SEO برای هر دسته، شمارش محصولات
- فیلترهای سمت کلاینت که **واقعا کار می‌کنند**: رنگ (با نمونه رنگی از داده)، سایز (ساخته‌شده از داده واقعی)، بازه قیمت، فقط تخفیف‌دار، فقط موجود
- ۵ حالت مرتب‌سازی (جدید/ارزان/گران/محبوب/بیشترین تخفیف)، Load More صفحه‌ای (۱۲تایی)، شمارنده نتایج، حالت «پیدا نشد»، Breadcrumb
- **Drawer فیلتر تمام‌صفحه در موبایل**
- لینک مقاله مرتبط هر دسته در پایین صفحه

### صفحه محصول (۹۲ صفحه استاتیک)
- گالری با thumbnail و **زوم در هاور (دسکتاپ) + Lightbox تمام‌صفحه**
- انتخاب رنگ/سایز با قیمت و **موجودی واقعی هر تنوع**؛ هشدار «تنها X عدد باقی مانده»؛ **غیرفعال‌شدن دکمه خرید برای تنوع ناموجود** (باگ پیدا و رفع شد در QA)
- تب‌ها: توضیحات، مشخصات، **راهنمای سایز اختصاصی هر دسته** (جدول سایز بر اساس اندازه بدن)، ارسال و بازگشت، دیدگاه‌ها (۱۵۲ نظر واقعی‌نما + فرم ثبت دیدگاه با وضعیت «در انتظار تأیید»)
- دکمه علاقه‌مندی، اشتراک‌گذاری تلگرام/واتساپ، **نوار چسبنده خرید موبایل (Sticky ATC)**
- بخش «محصولات مرتبط» (هم‌دسته + هم‌برند) و «استایل را کامل کنید» (نقشه مکمل‌ها بین ۲۰ دسته)
- Schema.org کامل: Product (قیمت/موجودی/امتیاز) + BreadcrumbList

### Wishlist / Quick View / Compare
- علاقه‌مندی‌ها با LocalStorage، شمارنده در هدر و Bottom Nav، صفحه اختصاصی با حذف
- **Quick View مودال** با انتخاب رنگ/سایز و افزودن به سبد بدون خروج از صفحه
- **مقایسه تا ۴ محصول** با جدول کامل (قیمت، دسته، برند، رنگ، سایز، جنس، نگهداری، امتیاز، موجودی، خرید)

### مجله مود — ۱۵ مقاله Editorial
- آرشیو با مقاله شاخص تمام‌عرض، چیپ‌های دسته‌بندی (۴ دسته) با فیلتر لحظه‌ای، متادیتا (نویسنده/تاریخ/زمان مطالعه)
- قالب مقاله ادیتوریال: هیرو با روکش، **فهرست مطالب چسبنده با anchor**، نقل‌قول‌ها، لیست‌های فارسی، **کارت محصولات واقعی داخل متن** (`[پ:اسلاگ]`)، باکس CTA، مقالات مرتبط، Schema Article
- هر مقاله ۴۵۰–۷۵۰ کلمه محتوای واقعی‌نما با H2/H3 متعدد (راهنمای فرم بدن، مینیمال، مانتوی موقعیت‌ها، ترندها، ترکیب رنگ، خرید آنلاین، سایز، نگهداری بافت، پارچه‌ها، کمد کپسولی، پالتو، Smart Casual، مجلسی، اکسسوری، ۱۰ اشتباه)

### سبد و Checkout
- سبد: جدول اقلام با محافظ موجودی، نوار پیشرفت ارسال رایگان، کوپن **درصدی/مبلغی با سقف تخفیف و حداقل سفارش** (۵ کد فعال)، پیشنهاد تکمیل استایل
- تسویه با اعتبارسنجی کامل (موبایل ۰۹…، کدپستی ۱۰ رقمی، ایمیل)، ۳ روش ارسال، ۲ روش پرداخت، خلاصه زنده
- درگاه آزمایشی (موفق/ناموفق با رمز تست) و رسید با تایم‌لاین وضعیت

### SEO نسخه ۲
- متای اختصاصی هر صفحه + Canonical + Open Graph کامل + Twitter Card + theme-color
- **JSON-LD**: Organization، WebSite+SearchAction، Product، BreadcrumbList، Article — تأییدشده در QA (۴ اسکیمای صفحه محصول)
- **sitemap.xml با ۱۴۵ URL** (۹۲ محصول + ۲۰ دسته + ۴ کالکشن + ۱۵ مقاله + صفحات سیستم) و robots.txt
- 404 اختصاصی با noindex؛ صفحات پنل و سبد از ایندکس خارج

### صفحات استاتیک بازنویسی‌شده
درباره (داستان برند ۵ پاراگراف)، تماس (کارت اطلاعات + فرم ذخیره در پنل)، FAQ (۸ آکاردئون)، ارسال و بازگشت، قوانین، حریم خصوصی، **راهنمای سایز** — همه با محتوای کامل فارسی

### تصاویر — ۱۷۹ فایل WebP محلی (۱۱MB)
- **۱۶۶ تصویر واقعی فشن** از موتور جست‌وجوی تصویر با ۲۴ کوئری هدفمند (پالتو، ترنچ، بلیزر، مانتو حجابی، شومیز، بافت، هودی، پالازو، جین، دامن، مجلسی، ماکسی، ست، کیف، شال، کمربند، کفش، بنر ادیتوریال، بوتیک، تکسچر پارچه)
- کراپ استاندارد (محصول ۳:۴ = ۷۲۰×۹۶۰، بنر ۱۶:۹)، تبدیل WebP کیفیت ۸۰، lazy loading و نسبت ابعاد ثابت (بدون Layout Shift)
- **QA بصری با ۶ contact-sheet**: ۱۷ تصویر نامناسب (کولاژ، متن استوک، کاتالوگ، مدل بدون ارتباط) شناسایی و با جست‌وجوی هدفمند جایگزین شد؛ نهایتاً فایل‌های مشکل با کپی از استخر سالم اصلاح و ۵ فایل بدون ارجاع حذف شدند
- مدل‌های متنوع شامل استایل‌های حجابی امروزی مناسب بازار ایران

### پنل مدیریت نسخه ۲
- **صفحات جدید**: مدیریت کالکشن‌ها (نام/اسلاگ/تصویر/محصولات/ترتیب/فعال) و بنرهای هیرو (برچسب/تیتر/زیرتیتر/تصویر/CTA/لینک/ترتیب) — تغییرات بلافاصله در فروشگاه همان مرورگر
- **فرم محصول توسعه‌یافته**: فیلد پرفروش، نشان جدید، **تصویر دوم هاور** با انتخاب از گالری، تنوع‌ساز خودکار، SEO
- **گالری رسانه v2**: فهرست تصاویر از داده واقعی (بجای ۱۸ نام هاردکد)
- مقالات v2 با فیلدهای cover/readTime/author و پشتیبانی مارکر محصول در متن
- داشبورد KPI + نمودار خطی فروش ۳۰ روزه + میله‌ای/دونات وضعیت سفارش‌ها (SVG سبک، بدون کتابخانه)

## ۳. مشکلاتی که در QA پیدا و رفع شد

1. **fetch آدرس db.json بدون اسلش** (`/parsimezon-storedata/db.json`) → بوت‌استرپ دمو کلاً شکست خورده بود؛ رفع شد با استفاده از BASE با اسلش
2. **`config.cats` تعریف‌نشده** در موتور فروشگاه → کرش رندر گرید؛ رفع شد
3. **checkout به `#ps-seed` حذف‌شده ارجاع می‌داد** → خلاصه سفارش و دکمه پرداخت کار نمی‌کرد؛ رفع شد با تزریق JSON روش‌های ارسال
4. **دکمه خرید فعال روی تنوع ناموجود** → غیرفعال‌سازی دکمه اصلی و چسبنده در انتخاب تنوع
5. **نرمال‌سازی ناکافی جستجو** → افزودن NFKC برای حروف عربی presentation-forms
6. **۱۷ تصویر نامناسب** در QA بصری → جایگزینی/حذف
7. توکن CSS قدیمی `--text-soft` در ۴ صفحه → اصلاح به `--c-text-soft`
8. عنوان صفحات پنل با مسیر دارای اسلش انتهایی → نرمال‌سازی
9. **مارکرهای مقاله بدون نگاشت** → ۲۸ مارکر به اسلاگ واقعی محصول نگاشت شد (کارت محصول در متن مقاله فعال شد)
10. **فایل‌های node_modules و سندباکس بین پیام‌ها** → کلون مجدد از GitHub و نصب مجدد

## ۴. نتیجه Build و تست‌ها

- **Build**: هر دو اپ بدون خطا؛ خروجی نهایی ۲۲MB؛ همه فایل‌های JS باندل‌شده با node --check سالم
- **تست E2E خرید ۱۰ مرحله‌ای روی نسخه ۲ (localhost با مسیر production-مانند)**: انتخاب محصول ✓ افزودن با تنوع ✓ سبد + کوپن WELCOME10 (−۲۳۶٬۰۰۰ با سقف ۳۰۰هزار) ✓ فرم تسویه با اعتبارسنجی ✓ ثبت ✓ درگاه با مبلغ صحیح ۲٬۲۱۳٬۰۰۰ ✓ پرداخت موفق ✓ رسید PS-48221 با وضعیت‌ها ✓ سبد خالی ✓ **سفارش در داشبورد پنل ✓**
- **فیلترها**: رنگ/قیمت/سایز/مرتب‌سازی/Load More/Drawer موبایل — همه تست‌شده
- **جستجو**: پیشنهاد زنده با تصویر و قیمت + نرمال‌سازی عربی/فارسی
- **موبایل (۳۹۰×۸۴۴)**: بدون اسکرول افقی، گرید ۲ستونه، Bottom Nav، Sticky ATC، Drawer فیلتر، اسکرین‌شات بررسی‌شده
- **Console**: بدون خطای JS در جریان‌های اصلی
- **لینک‌ها**: مسیرهای جدید /category/، /collection/، /journal/ در هدر/فوتر/sitemap هم‌خوان؛ مسیر قدیمی /blog حذف شد

## ۵. موارد باقی‌مانده / محدودیت‌های صادقانه

1. **انتشار**: طبق مأموریت انجام نشد — با تأیید شما: `git checkout main && git merge v2-upgrade` + اجرای `ps_deploy.sh` (یا ساخت PR از لینکی که GitHub برگرداند)
2. تصاویر محصول از وب استخراج شده‌اند؛ برای استفاده تجاری واقعی باید لایسنس هر تصویر بررسی یا عکاسی اختصاصی انجام شود
3. مدیریت کامل تنوع‌ها (رنگ/سایز جدید پس از ساخت) در فرم پنل «ساخت خودکار» است — ویرایش تک‌تک موجودی ممکن، افزودن رنگ جدید پس از ساخت نیاز به ساخت مجدد دارد
4. مقالات پنل در نسخه دمو فقط روی همان مرورگر اعمال می‌شوند (محدودیت معماری Static/LocalStorage — مستند و در UI پنل ذکر شده)
5. Lighthouse رسمی اجرا نشد (فقط بهینه‌سازی‌های ساختاری: WebP، lazy، aspect-ratio، فونت preload، CSS واحد، JS بدون کتابخانه خارجی)
